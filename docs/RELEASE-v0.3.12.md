# v0.3.12 · 首次公开测试发布

在飞书 Docx / Wiki 文档里点击「保存全文与素材」，将支持的正文、图片、视频和附件保存到浏览器下载目录。

## 下载与安装

下载下方 **feishu-local-exporter-v0.3.12.zip**，解压后在 Chrome / Edge 扩展管理页面开启开发者模式，选择「加载已解压的扩展程序」。选择直接包含 `manifest.json` 的文件夹，然后刷新飞书文档。

`Source code` 为开发者源码包；普通用户请选择上述安装 ZIP。`SHA256SUMS.txt` 用于核对安装包 SHA-256。

## 功能

- Markdown 正文与本地素材相对链接。
- 原图读取、图片格式识别，以及可直接下载的视频和文件附件。
- 独立代码文件、普通表格 CSV / HTML。
- 读取与下载进度、取消、缺失素材重试及本地导出报告。

## 已知限制

- 嵌入电子表格和多维表格仅保留原表链接；第三方应用块保留说明。
- 分片视频合并、Lark 国际版和整库批量导出尚未支持。
- 超过 64 MiB 图片的直接下载路径尚未完成真实大文件验收。
- 部分素材可能因权限、网络或浏览器提示失败；代码/表格等生成附件失败时需重新导出整篇。
- 主要验证环境为 Windows；其他系统及不同飞书租户仍需更多测试。
- 手动加载版本不会自动更新。Markdown 不保证逐像素复现原页面。
