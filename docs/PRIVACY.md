# 隐私与权限说明

本说明适用于 v0.3.12。插件没有开发者服务端，不包含统计 SDK，不自动上传文档或错误报告。

## 数据流

用户点击保存后，插件读取当前飞书文档的页面结构，必要时向飞书接口请求后续正文和素材。请求使用当前浏览器登录状态；同源请求可能读取页面 CSRF Cookie 并用于飞书请求头。插件不要求用户填写密码或复制 Cookie。

正文、图片、视频、代码、表格和导出报告通过浏览器下载管理器保存到本地。临时下载任务信息保存在 `chrome.storage.session`；图片临时 Blob 会释放或到期清理。浏览器本身会保留下载历史。

导出报告可能包含标题、来源 URL、内容块标识、嵌入表格标识及链接、素材文件名、大小、错误和服务域名。报告不会由插件自动发送给作者。用户自行上传报告到公开 Issue 时，这些内容会成为公开信息，请先脱敏。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 响应用户点击扩展工具栏按钮 |
| `scripting` | 注入页面按钮及在文档页面读取结构与素材 |
| `downloads` | 创建、检查、取消本插件下载，清理失败文件，打开文件所在位置；查找下载记录以避免同名目录冲突 |
| `storage` | 在会话内保存任务归属和临时资源信息 |
| `https://*.feishu.cn/*` | 访问飞书文档及其素材服务；自动内容脚本限定在 Docx / Wiki 路径 |

飞书服务和浏览器自身的数据处理规则由各自提供方决定。本说明仅描述本插件代码行为。
