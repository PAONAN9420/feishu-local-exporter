# 飞书文档本地导出

**在飞书文档里点一下，把正文、图片、视频和附件一起保存到本地。**

适用于 Chrome / Edge 的 Manifest V3 扩展。支持飞书新版 Docx，以及承载 Docx 的 Wiki 页面。

[下载 v0.3.12 公开测试版](https://github.com/PAONAN9420/feishu-local-exporter/releases/tag/v0.3.12) · [安装步骤](#安装) · [反馈问题](https://github.com/PAONAN9420/feishu-local-exporter/issues/new/choose) · [English](docs/README.en.md)

## 为什么做这个

我试过好几款飞书导出工具，始终没有找到让我满意的。想保存一篇文章时，我希望正文、图片、视频、代码和表格能一起落到本地，之后也方便查阅。

所以我做了这个插件：打开文档，点击「保存全文与素材」，沿用浏览器下载目录，按文章标题整理文件。现在把源码公开，欢迎大家试用，把遇到的问题和想要的功能告诉我。

## 能保存什么

| 内容 | 导出方式 |
| --- | --- |
| 正文 | Markdown，保留常见标题、列表、引用、链接和富文本样式 |
| 图片 | 读取原文件接口，按识别出的图片格式保存，并更新正文相对链接 |
| 视频与附件 | 保存可直接下载的文件；下载失败会显示提示 |
| 代码块 | 保留正文代码块，同时生成独立代码文件 |
| 文档内普通表格 | 正文表格 + CSV + HTML；HTML 保留支持的合并单元格 |
| 书签 | 保留链接与摘要 |
| 嵌入电子表格 / 多维表格 | 保留原表链接，**暂不导出单元格和记录数据** |

页面按钮显示读取、下载进度；支持取消、重试缺失素材和打开文件夹。出现未支持内容或缺失素材时，会明确显示「有缺项」，并写入导出报告。

导出目录示意（仅为结构示例，实际文件按文档内容生成）：

```text
浏览器下载目录/
└─ 文档标题/
   ├─ 文档标题.md
   ├─ images/
   ├─ videos/
   └─ attachments/
      ├─ code/
      ├─ tables/
      ├─ files/
      └─ export-report.json
```

## 安装

1. 打开上面的下载页面，下载附件 **`feishu-local-exporter-v0.3.12.zip`**。普通用户请选择这个安装包。
2. 解压到一个准备长期保留的文件夹。
3. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
4. 开启「开发者模式」，点击「加载已解压的扩展程序」。
5. 选择解压后直接包含 `manifest.json` 的文件夹。
6. 打开或刷新飞书 Docx / Wiki 文档，点击「保存全文与素材」。导出时保持当前文档打开。

使用近期版本的桌面 Chrome / Edge。首次发布主要在 Windows 环境验证，其他操作系统尚未验证。此发行包通过手动加载安装，尚未上架扩展商店，也不会自动更新。

浏览器若开启了「下载前询问每个文件的保存位置」，请关闭该选项以减少逐个确认。若出现自动下载或安全提示，请先在浏览器里处理，再重试。

更新时下载新包并解压到新的版本文件夹，移除旧扩展后加载新文件夹，再刷新飞书页面。不要同时启用两个副本。

## 当前限制

- 仅匹配 `*.feishu.cn` 的 `/docx/`、`/wiki/` 页面；不支持国际版 Lark 域名、旧版 Docs，以及整库批量导出。
- 需要当前浏览器可以访问文档及相应素材；受权限限制的资源可能失败。请仅导出你有权保存的内容。
- 嵌入电子表格、多维表格仅保留链接；第三方应用块保留说明；不支持分片视频合并。
- 超过 64 MiB 的图片直接下载路径尚未完成真实大文件验收；异常大小、浏览器拦截或超时可能造成缺项。
- Markdown 是内容归档格式，不保证与飞书页面逐像素一致，也不是 PDF / Word 导出。
- 「重试缺失素材」用于图片、视频和文件素材；代码、表格等生成附件失败时，请重新导出整篇文档。
- 导出依赖飞书网页内容结构和接口，页面更新可能需要跟进适配。不同租户、权限、文档类型仍需要更多实际反馈。

## 数据与权限

导出由用户点击启动。插件利用当前页面登录状态向飞书读取文档与素材，通过浏览器下载管理器写到本地；当前代码没有开发者服务端、统计 SDK 或自动上传反馈功能。

导出报告包含文档标题、来源链接、内容块标识、素材状态及错误信息。提交 Issue 前请删去不方便公开的信息，也不要上传 Cookie、账号凭据或私有文档全文。

详见 [隐私与权限说明](docs/PRIVACY.md)。本项目为独立开源项目，与飞书官方无隶属关系。

## 开发与验证

环境：Node.js 24+；打包 ZIP 另需 PowerShell 7（`pwsh`）。

```sh
npm ci
npm test
npm run package
```

`npm test` 先构建，再运行自动测试。可加载扩展位于 `dist/`，ZIP 和 SHA-256 校验文件位于 `artifacts/`。重复打包前请另存已有 ZIP 或使用新的工作目录，脚本不会覆盖已有归档。

测试使用虚构文档结构和模拟网络，不需要飞书账号；自动测试通过不代表所有真实文档均已兼容。公开仓库不包含用户文档或浏览器配置。
